# 坑爹跑酷 · Trap Runner

一个打开浏览器就能玩的「坑向跑酷」小游戏——画面看着人畜无害，陷阱专治手快。

## 怎么玩

| 按键 | 作用 |
|---|---|
| `←` `→` / `A` `D` | 左右移动 |
| `空格` / `↑` / `W` | 跳跃（**按住可以连续弹跳**） |
| `R` | 重开本关 |
| `M` | 开关音乐 |
| `N` | 跳过本关（死满 8 次后可用） |

目标：走到右边的绿色门。碰到尖刺或者掉下去就重来，**死了不惩罚，重开很快**。

## 有什么坑

- **假地板**：看着是地板，踩上去 0.4 秒就塌
- **一触即碎**：踩上去 0.3 秒就碎，别停留
- **坠落尖刺**：走到某处突然从地板/天花板弹出来
- **误导箭头**：指的方向不一定是活路
- **突然出现的墙**：跑过去才长出来

8 个关卡，最后一关是综合考验。

## 技术特点

- **单文件**：整个游戏就一个 `index.html`，双击即玩，零依赖、零构建
- **零素材**：画面全部用 Canvas 代码绘制，没有一张图片
- **零音频文件**：BGM 和音效全部由 Web Audio API **实时合成**（芯片风 Am-F-C-G 循环）
- 手感：土狼时间、跳跃缓冲、按住连跳、可变跳跃高度、屏幕震动、死亡粒子

## 运行

直接用浏览器打开 `index.html` 就行。

## 开发说明

`index.html` 底部把核心对象挂在 `window.__TRAP__` 上，方便用 Node 做无头测试
（模拟浏览器环境后可以驱动游戏循环，验证物理与陷阱逻辑）。
