# Trap Runner · 陷阱奔跑

一个 **16 关**的陷阱平台跳跃游戏。全部用原生 Canvas 2D 写成，**单文件、零依赖**。

> 主题：*你以为的，不是你以为的。*

---

## 立即开玩

### 在线玩（推荐）

https://caicai114114514-fzu.github.io/trap-runner/

### 下载玩

1. 点右上角 **Code → Download ZIP**
2. 解压后：
   - **Windows**：双击 `TrapRunner.exe`（自动全屏窗口，需要 Edge）
   - **任意系统**：双击 `index.html`（用浏览器打开）

## 操作

| 按键 | 作用 |
|---|---|
| `← →` / `A D` | 移动 |
| `空格` / `↑` | 跳跃 |
| `R` | 重来本关 |
| `M` | 音乐开关 |
| `Enter` | 确认 |

---

## 内容

- **3 个大关 × 5 关 + 魔王关 = 16 关**
- 四大主题：`脚下不稳` / `眼见为虚` / `机关重重` / `险路尽头`（最后一关 4-1 表魔王）
- **3 把隐藏钥匙**：分别在 1-2 / 2-4 / 3-3，交付钥匙会死 —— 这是设计
- **8 个成就**：4 个通关成就 + 4 个隐藏成就

### 机关

假地板、消失板、假尖刺、旋转墙、追踪导弹、假门、假币、活塞、跳板、变形门……

---

## 技术

| 项 | 说明 |
|---|---|
| 体积 | 游戏本体 **216KB**，单文件 `index.html` |
| 依赖 | **0**（无框架、无图集、无音频文件，音效是 Web Audio 实时合成） |
| 渲染 | Canvas 2D，960×540 逻辑分辨率，CSS 自适应铺满窗口 |
| 存档 | `localStorage`，记录通关、钥匙、死亡数、成就 |
| 测试 | `trap_test.js`：**238 项断言**，Node 环境下跑逻辑 + 渲染可见性检查 |

## 开发

```bash
# 起本地服务器（避免 file:// 的跨域限制）
python -m http.server 8000

# 跑测试
node trap_test.js
```

### 调试参数

```
?lv=N              直接进入第 N 关
?screen=world      一级目录
?screen=levels     二级选关
?w=N&ach=1         看第 N 大关的成就面板
?dbg=1             显示点击坐标调试
?reset=1           清空存档
```
